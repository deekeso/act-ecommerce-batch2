# DigiShop E-Commerce

A modern e-commerce web application built using Vue.js 3 and TypeScript

## Features

- 🛍️ **Product Management**

  - Browse products with detailed descriptions and prices
  - Filter products by categories
  - Search functionality with auto-complete
  - Detailed product pages with images and descriptions

- 🛒 **Shopping Cart**

  - Add/remove items from cart
  - Adjust product quantities
  - Real-time cart total calculation
  - Persistent cart data using local storage

- 👤 **User Authentication**

  - User registration
  - Login/logout functionality
  - Profile management
  - Secure authentication system

- 💫 **User Experience**
  - Responsive design
  - "Just For You" product recommendations
  - Dynamic product loading with "Show More" functionality
  - Easy checkout process

## TechStack Used

- Vue.js 3
- TypeScript
- Element Plus UI Library
- Vue Router for navigation
- Pinia for state management

## Project Structure

```
src/
├── components/         # Reusable Vue components
├── views/             # Page components
├── stores/            # Pinia state management
├── routes/            # Vue router configuration
├── types/             # TypeScript type definitions
└── utils/             # Utility functions
```

## Getting Started

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Build for production:

```bash
npm run build
```
